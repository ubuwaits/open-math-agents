# The odd simple-group subproblem

The second hypothesis of PR 19598 asks whether every finite simple group of odd order is commutative. Yawara's Lean formalization of the Feit–Thompson theorem proves solvability for every finite odd-order group. Lean's mathlib theorem `IsSimpleGroup.comm_iff_isSolvable` gives the requested commutativity. The independent lean-eval checker accepted Yawara's submission on 16 July 2026.
